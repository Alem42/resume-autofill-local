# 离线资料目录

目录随扩展提供，只在本机设置页读取。输入的检索词不会发送到目录服务。所有目录保留原始代码、来源网址和版本；设置页保存名称，允许自定义，不会自动把国外学校、专业或研究生学科改为国内本科代码。

| 文件 | 内容 | 来源 |
| --- | --- | --- |
| `schools-cn.json` | 2026 年普通及成人高等学校共 3,196 条名称与学校代码 | 教育部[全国高等学校名单](https://www.moe.gov.cn/jyb_xxgk/s5743/s5744/202606/t20260618_1441074.html)的两份附件 |
| `major-categories-cn.json` | 13 个学科门类、92 个本科专业类；代码长度区分层级 | 教育部[普通高等学校本科专业目录（2026年）](https://www.moe.gov.cn/srcsite/A08/moe_1034/s3882/202604/t20260427_1434931.html) |
| `majors-cn.json` | 883 条本科专业记录，保留原始代码及 T / K 标记 | 同上 |

883 条专业记录包含同名专业，设置页按名称去重后显示 882 个名称。代码仍完整保留在目录中，不按名称去重原始记录。民族、政治面貌、语种、称谓等常用选项另见 `shared/catalogs.js`。

`scripts/build-catalogs.py` 是开发期整理工具，依赖 Python 的 `pypdf` 和 `xlrd==2.0.2`，将教育部公开 XLS / PDF 附件转为上述 JSON；下载缓存位于 Git 忽略的 `.preview/official-catalogs/`。它不读取用户简历，也不在扩展运行时执行。日常使用无需安装 Python 或 PDF 库。

以上是公开目录的事实数据及来源说明，不代表教育部为本扩展背书，也不将第三方原始文件的权利归入项目 MIT 许可。目录不是国际学校、研究生学科或所有历史名称的完整数据库；缺项请使用自定义输入。
