# 简历自动填充 Chrome 扩展

AI 智能识别页面表单，一键自动填充简历信息的浏览器扩展。支持 Chrome 和 Edge。

## ✨ 功能特性

- 🤖 **AI 智能识别**：借助大模型理解表单字段含义，无需硬编码关键词
- 📄 **PDF 导入**：上传 PDF 简历，自动解析为结构化数据
- 🔍 **智能识别简历页面**：自动判断页面是否为简历填写页，仅在需要填简历的页面显示按钮
- ➕ **自动展开"添加"区块**：工作/教育/项目经历初始为空时，自动点击"添加"，只给简历里有数据的区块新建字段块
- 🎯 **一键填充**：点击浮动按钮，自动填充所有匹配的表单字段
- ↩️ **撤回功能**：填充错误？一键撤回重新填充
- 💾 **数据管理**：支持导入/导出 JSON 数据
- 🧩 **跨组件库兼容**：行为驱动的组件识别（不依赖特定框架类名），支持任意自定义组件库（如 Moka 等 ATS 系统），兼容 React 受控组件与 iframe 内嵌表单
- 🌐 **跨浏览器**：同时支持 Google Chrome 和 Microsoft Edge

## 📦 安装方法

### Chrome 浏览器

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `resume-autofill` 文件夹
5. 扩展安装完成，图标会出现在浏览器工具栏

### Edge 浏览器

1. 打开 Edge，访问 `edge://extensions/`
2. 开启「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择 `resume-autofill` 文件夹
5. 扩展安装完成

## 🚀 使用方法

### 1. 配置 AI 模型

首次使用需要配置大模型 API：

1. 点击浏览器工具栏的扩展图标
2. 在「AI 模型设置」区域填写：
   - **API Base URL**：如 `https://api.openai.com/v1`
   - **API Key**：你的 API 密钥
   - **模型名称**：如 `gpt-4o-mini`
3. 点击「保存所有信息」

### 2. 填写简历信息

**方式一：手动填写**

在扩展弹窗中逐个填写：
- 基本信息（姓名、电话、邮箱等）
- 教育经历（支持多条）
- 工作经历（支持多条）
- 求职意向
- 自我评价

**方式二：PDF 导入**

1. 点击「从 PDF 简历导入」按钮
2. 选择你的 PDF 简历文件
3. AI 会自动解析并填充表单
4. 检查并修正后点击保存

### 3. 自动填充表单

扩展会**自动识别「需要填写简历」的页面**（招聘投递页、求职登记页等），只在识别到的页面显示右下角浮动按钮：

- 页面存在可填写的表单字段，且字段标签或页面 URL 包含简历相关信号（如「期望职位」「工作经历」「学历」，或 job/apply/招聘/投递 等）
- 登录页、搜索页、评论区等无关页面不会出现按钮
- 表单异步渲染的页面（SPA），表单出现后按钮会自动显示

使用步骤：

1. 打开招聘网站的简历填写页面
2. 页面右下角出现「自动填充」浮动按钮
3. 点击按钮，等待 AI 识别（通常约 30-60 秒，视模型与字段量而定；推理模型 / 字段较多的页面会慢一些，扩展会并行分块识别加快返回）
4. 字段会自动填充并高亮显示
5. 如需撤回，再次点击按钮即可

> ➕ 部分网站（如 B 站校招）的工作/教育/项目经历区块初始为空，需要先点「添加」才出现输入区域。点击「自动填充」时扩展会自动完成这一步：**只给简历里确实有数据的区块点「添加」**（教育/工作/项目/语言），其余区块不新建空块；新增块数 = 简历条目数 − 页面已有块数（如页面已有一段实习经历、简历里有两条，则自动补点一次「添加」），已有块数 ≥ 简历条数时不会重复添加。

> 💡 若某些页面误判（应显示未显示、或多余显示），可调整 `content/content.js` 中的关键词列表：`RESUME_STRONG`（简历/求职强信号）、`RESUME_MEDIUM`（个人信息信号）、`NEGATIVE_KEYWORDS`（登录/搜索/评论等拦截词）。

## 🧪 测试

项目包含两个测试页面：

- `test.html`：常规简历表单（字段已渲染，含籍贯省/市级联选择器，用于验证选择器/级联填充）；带 `?stubborn` 参数（如 `test.html?stubborn`）会让级联"选中后面板残留、忽略文档级点击关闭"，模拟 B 站忽略合成事件的场景，用于验证填充后面板能逐项收起
- `test-add.html`：参照 B 站校招简历结构，工作/教育/项目经历初始为空，点「添加」才出现字段块；带 `?seed` 参数（如 `test-add.html?seed`）会预置 1 条工作经历，用于验证「页面已有部分块、简历条目更多时自动补齐差额」的增量场景

验证步骤：

1. 在 Chrome/Edge 中打开测试页（会被识别为简历填写页，按钮自动出现）
2. 确保已配置 AI 模型和简历信息
3. 点击右下角「自动填充」按钮
4. 观察表单字段是否被正确填充；`test-add.html` 还应看到只有简历里有数据的区块被自动"添加"并填入，且新增块数 = 简历条目数 − 页面已有块数（如简历有 2 条工作、页面已有 1 块，则自动补 1 块）

## 🔧 技术栈

- **Manifest V3**：最新的 Chrome 扩展规范
- **PDF.js**：Mozilla 开源的 PDF 解析库
- **OpenAI-compatible API**：支持任何兼容 OpenAI 接口的大模型服务

## 📝 支持的 LLM 服务

任何兼容 OpenAI Chat Completions API 的服务均可使用：

- OpenAI (GPT-4, GPT-4o, GPT-4o-mini)
- Claude (通过 API 转换)
- 国产大模型（通义千问、文心一言等，需使用兼容接口）
- 本地部署的模型（Ollama、LM Studio 等）

## 🐛 常见问题

**Q: 点击填充按钮没反应？**  
A: 检查是否已配置 AI 模型的 Base URL、API Key 和模型名称。

**Q: 某些字段没有被填充？**  
A: AI 可能无法匹配到对应的简历信息，可以手动补充这些字段。

**Q: 某些招聘网站（如 Moka）字段填不上？**  
A: 已升级为行为驱动的组件识别，不依赖特定框架类名，兼容 React 受控组件与 iframe 内嵌表单。请确保加载的是最新版本扩展（重新加载扩展后刷新页面）。若仍有字段未填充，可手动补充。

**Q: PDF 导入失败？**  
A: 确保 PDF 是文本格式（非扫描件），且 AI 模型配置正确。

**Q: 支持哪些浏览器？**  
A: Chrome 88+ 和 Edge 88+（基于 Chromium 的版本）。
