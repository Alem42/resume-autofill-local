# 简历填写助手：本机资料 + 手动确认

这是一个本机加载的 Chrome / Edge 扩展，不需要后端服务、npm 依赖或 PDF 文件。

## 安装到这台电脑

1. 使用 Chrome 120+ 或近期版本 Edge。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`。
3. 打开开发者模式，选择“加载已解压的扩展程序”。
4. 选择 **E:\Project\AiAgent\resume-autofill\resume-autofill**。这是包含 `manifest.json` 的内层目录。
5. 如果安装了旧版，先移除旧版或在原条目点击重新加载，然后刷新原来打开的招聘网页。旧网页中的旧脚本只有刷新后才会消失。
6. 点击扩展图标 → “编辑个人信息与 API”。

旧版的规范个人信息会迁移到新的本机存储结构。旧 API Key、任意 Base URL 和待处理 PDF 结果会删除，不会自动把其他服务的密钥发给 DeepSeek。

## 配置个人信息和 DeepSeek

在完整的个人信息页面填写姓名、联系方式、教育、工作、项目、技能与求职意向等，点击“保存个人信息与设置”。

- 接口固定为 `https://api.deepseek.com/chat/completions`，只允许该 HTTPS 域名。
- 模型提供 `deepseek-flash` 和 `deepseek-v4-pro`，默认使用 Flash。
- 填入自己的 DeepSeek API Key，点击“保存后测试连接”。
- 默认只把密钥保存在浏览器会话内；浏览器重启、扩展重新加载后需要重新输入。
- 可以主动勾选“在本机记住 API Key”。这会持久保存到浏览器本地存储，未额外加密。密钥不会回显、导出或提供给网页脚本。
- 个人信息持久保存在本机，不使用浏览器账号同步。
- 信息过长时会报错，不会悄悄截断经历正文。

[DeepSeek 官方文档](https://api-docs.deepseek.com/)

“本机运行”指扩展、个人资料、确认与填写逻辑都在本机。字段匹配仍需调用 DeepSeek 云 API：只发送网页字段的标签、占位符、name、组件类型，以及被允许的资料项名称和编号；**不发送存储的姓名、电话、邮箱、经历正文等个人资料值，也不发送网页 URL、全文或已有输入值**。网页自身提供的标签或占位符可能包含私人文字，请只在可信页面使用。

## 每次填写

1. 打开可信招聘网站的填写页面。
2. 手动展开教育 / 工作 / 项目区块，按需要添加经历条目。
3. 点击扩展图标，打开“本页手动检测”开关。这次操作仅授权当前标签页主文档。
4. 检测到简历表单时，会打开扩展自己的确认窗口。核对完整网址，选择本次允许填写的资料。身份证号、详细地址、紧急联系人和薪资等敏感项默认不选。
5. 点击“确认资料范围，匹配字段”。此时会调用 DeepSeek，尚未向招聘网页写入任何个人资料。
6. 检查“填写预览”，取消勾选不需要的字段，点击“确认填写所选字段”。
7. 回到网页逐项检查，手动保存 / 提交。

默认跳过已有值。如果确实要覆盖，需要明确勾选“允许覆盖已有内容”。

取消或关闭确认窗口会停止检测，并取消尚未完成的 AI 请求；关闭发生在填写过程中时，已经写入的字段不会自动撤回。页面刷新、跳转、更换文档后，旧确认失效，需要重新开启。每次填写结束后关闭检测，不会后台扫描其他页面，也不会自动点击“添加”、保存或投递。

检测最长 60 秒，确认有效期 10 分钟。API 请求最长 25 秒，超时不会自动重试。没有表单时可先展开区块再重新开启。只支持主文档；跨域 iframe 中的表单不会获得授权。浏览器设置页、扩展商店等受保护页面不能注入。

## JSON 备份

设置页支持导出 / 导入个人信息 JSON。只允许这些顶层字段：

`basic`、`education`、`work`、`projects`、`jobIntention`、`languages`、`certificates`、`skills`、`selfEvaluation`。

未知字段、密钥、API 配置、任意 URL 配置和原型污染键会被拒绝。导入只更新表单，检查并保存后才会替换本机资料。备份包含私人信息，勿随意分享。旧版包含 `llm` 的 JSON 不能直接导入，需要先去掉模型配置部分。

## 安全边界

- 移除了 PDF 导入、PDF.js 和旧版的网页浮动按钮。
- 没有 `<all_urls>`、常驻内容脚本或全部 iframe 注入。网页访问由 `activeTab` 的手动操作临时授权。
- 个人资料和密钥的存储限制为 `TRUSTED_CONTEXTS`，内容脚本不能读取。
- 来源不正确的消息无法开启检测、读取资料、调用 API 或确认填写。
- 检测授权绑定标签页、文档 ID、完整 URL 和随机令牌，确认绑定扩展确认窗口。
- 模型只允许返回字段 ID 与资料项 ID；任意 selector、value、代码、重复映射或未授权编号都会拒绝。
- 填写只使用扫描时保存的元素引用。元素被替换、隐藏、禁用、变成密码框或改变标签后跳过，不会按模型生成的选择器寻找其他元素。
- 表单密码、文件、隐藏、验证码/搜索及提交控件不参与填写。默认不覆盖已有值。
- 不记录简历内容、密钥或填充值；API 不跟随重定向，不自动重试，不发送 cookies。
- UI 不使用远程脚本、第三方库或把个人资料拼接为 HTML。设置页的导入也经过白名单校验。

确认写入后，目标网页及其脚本可以读取填写内容，部分网站会自动保存。扩展不能保证招聘网站或 DeepSeek 的服务端行为；使用时应核对目标站点与预览。

## 本机测试

加载扩展后，打开同目录的 `test.html` 或 `test-add.html`。直接用 `file://` 打开时，请在扩展详情页允许访问文件网址。动态区块测试需要先手动点“添加”。

运行源码安全与流程测试（无需安装依赖）：

```powershell
cd E:\Project\AiAgent\resume-autofill\resume-autofill
node --test tests/*.test.js
```

测试使用虚构个人信息与模拟 API，不会调用真实 DeepSeek，不会产生 API 费用。真实接口需要用户在设置页填入自己的密钥验证。

## 结构

- `options/`：完整的本机个人信息与 API 设置页。
- `popup/`：当前页面的手动检测开关。
- `confirm/`：资料范围确认和填写预览窗口。
- `background/background.js`：后台入口。
- `shared/controller.js`：来源校验、临时授权、API 与确认流程。
- `shared/profile.js`：资料白名单、固定接口与 AI 结果验证。
- `content/content.js`：手动注入的只读检测与经批准的填写。
- `tests/`：无需联网的安全回归与流程测试。
