# 北森适配与资料设置改造（2.8.0）

日期：2026-10-20。依据[开源实现调研](open-source-autofill-research.md)落实北森公开组件的交互方式。扩展仍是本机资料、手动开启、范围确认、预览后写入；没有新增招聘网站常驻权限。

## 交互变化

| 场景 | 现在的处理方式 | 验收依据 |
| --- | --- | --- |
| 搜索型学校 | 输入后等待异步候选稳定，按完整名称、别名、唯一近似项选择，再读取外部已选值 | 实际 Phoenix Select / SelectList 的回调、异步学校夹具与独立操作 |
| 普通、搜索及分组下拉 | 识别真正的列表与选项；搜索高亮、标签和底部按钮不再误当菜单 | 实际 Phoenix SelectList 3.3.55 |
| 带原生 radio / checkbox 的选项 | 点击行内选择目标，检查选中状态；需要确定时再提交 | 真实 SelectList 的 checkbox / footer，以及 radio 夹具 |
| 北森左右待选弹层 | 识别 `constant-main-selector-container`，点击 `RadioUnchecked` 等 SVG，检查待选区，再点本弹层确定 | 根据公开招聘分包的 DOM 结构制作夹具；不是已登录企业官网实测 |
| 确认按钮 | 北森按钮实际监听在内部 `phoenix-button__wraper`，优先点击该目标；不点页面保存、投递、提交 | 实际 Phoenix 按钮及 SelectList 回调 |
| 日期 | 先读取网页精度；Phoenix 按年 → 月 → 日（如需要）推进，重新获取每次变化后的视图并读回 | 真实 DatePicker、MonthPicker，以及仅年份控件 |
| 范围日期 | 作为一组处理，分别定位左 / 右日历；两端都选择后核对实际提交值 | 真实 Phoenix DateRangePicker，两个不同年份的完整日期 |
| 用户手动接管 | 手填值优先，即使允许覆盖也保留；用户操作下拉 / 日历期间暂停后续滚动、打开菜单和写入，确认或关闭后继续 | 独立 agent 重新编辑已填学校、等待搜索、选择后恢复、中止测试 |
| 添加经历 | 按所选资料数量补足；明确的“是否有项目 / 实习等经历”门槛先选是，门槛不当作一条经历 | 多条教育、家庭、项目全链路及门槛回归 |

普通字段仍有 5 秒自动处理预算，学校 10 秒，共享范围日期共用一份预算；超时后跳过，不留下继续写入的后台任务。明确的手动选择等待有页面提示，不消耗其他字段的自动处理预算，可在确认窗口中止。浏览器后台休眠仍可能让页面事件延迟，实际填写时建议保持招聘页可见。

网站要求具体日期而资料只有年月时，报告缺少日期并留给人工补全，不再代填该月 1 日。只要求年份或年月的控件按对应精度填写。日期开关继续保留。

## 资料与设置

- 新增家庭情况：姓名、称谓、联系电话、工作单位、职位、政治面貌、是否本公司员工；各成员独立匹配，模糊模式也不会跨成员借用本人或他人的电话、政治面貌。
- 本人和已填写家庭成员的“是否本公司员工”默认否，仅用于明确的员工关系问题，不作为其他问题的通用“否”。岗位调剂单独保存，未填写不等于同意。
- 基本信息新增生源地、健康状况；生源地与户籍、籍贯分别保存。
- 教育分别保存学历、学位层次、学位门类、正式学位名称，以及专业所属门类、专业类别、专业名称。旧自由文本保留，不擅自推断或改写。
- 自我评价仍只有一个资料项，增加个人评价、个人简介、自述等识别名称，即使网站把它放在基本信息中也可匹配。
- 日期设置改为分别选年、月、日，保留原精度；所有并列条目可以上移 / 下移，边界按钮禁用，顺序保存后用于实际填写。
- 学校、专业与分类采用教育部公开目录的本机副本；民族、政治面貌、语言、称谓、学历等提供常用候选。可检索、可自定义。目录覆盖与来源见 [data/README.md](../data/README.md)。

设置页使用原生选择框和可输入的候选列表，没有将测试用 React 或北森组件打进生产界面。AI 仍只在本机规则无法决定候选时辅助选择编号；日期操作、弹层归属、确认和读回由本机代码负责。

## 本轮验证

| 测试 | 结果 |
| --- | --- |
| 单元及安全流程 | 143 项通过 |
| 7 组实际组件：Phoenix、Element UI、Element Plus、Ant Design、Arco、TDesign、Naive UI | 35 / 35 项通过，全部运行真实组件；原来的 3 项 Phoenix 下拉 DOM 重建已替换 |
| 允许覆盖开启 / 关闭的手动接管 | 6 个场景通过：输入、单选、学校下拉、日期编辑 |
| 北森虚构整页自动验收 | 62 / 62 匹配并填入，0 跳过、0 差异 |
| 实际 Phoenix 范围日期 | 2 / 2 接受并正确读回 |
| 独立 agent 从界面操作 | 整页 62 / 62；另测学校搜索、SVG 确认、日期、排序保存、390px 设置页、日期关闭和中止 |

测试依据组件 change / select 回调接受的值核验，同时检查协议、投递计数为零。独立操作发现并修复了仅年份误分类、中止显示异常，以及用户重开学校时被程序继续滚动打断的问题，见[独立操作记录](beisen-manual-qa.md)。匿名诊断新增选项待确认 / 已确认、日历年 / 月阶段及缺少日期原因，不包含实际个人资料值。

## 复现与范围

```sh
npm ci --ignore-scripts --legacy-peer-deps
npm test
npm run test:components
npm run test:beisen
npm run test:browser
```

手动浏览虚构页面：运行 `npm run test:beisen:serve`，打开 `http://127.0.0.1:43821/test-beisen.html`。页面可直接按虚构资料测试，不调用 DeepSeek、不使用浏览器中扩展保存的真实资料；设置页链接打开的是消息接口被替换的本机测试副本。`range.html` 提供实际范围日期组件。关闭服务终端即可停止。

公开包包括 [Select](https://www.npmjs.com/package/@beisen-phoenix/select)、[SelectList](https://www.npmjs.com/package/@beisen-phoenix/select-list)、[DatePicker](https://www.npmjs.com/package/@beisen-phoenix/date-picker)，锁定 3.3.55，均仅作开发测试依赖；元数据声明 ISC。范围日期包的旧式 `util.isArray` 导入用测试专用兼容层转为 `Array.isArray`。这些第三方包、转换目录用的 PDF 库都不进入生产扩展运行路径。

本轮覆盖调研中与当前字段填写直接相关的选择、搜索、分组、行内单选 / 复选、左右确认、年月日和范围日期。没有宣称 Phoenix 所有版本、所有多选组合、任意级联 / 远程虚拟树、上传、时间秒值等控件已全部兼容。没有登录中国人保或其他企业账户提交虚构简历，也不把模拟页通过率等同于企业官网覆盖率。
