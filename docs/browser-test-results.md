# 浏览器兼容性回归记录

测试日期：2026-10-16；版本：2.6.0。

使用本机 Edge 的无界面模式，在真实 DOM 中执行生产内容脚本，由生产后台控制器驱动。扩展 API 和 DeepSeek 响应通过本机测试桥接模拟，不使用真实求职资料或 API Key。页面单独保存接受的值，测试程序核对该值，而不是仅相信扩展返回“已填写”。

| 场景 | 匹配字段 | 成功填写 | 预期跳过 | 网页独立核验 |
| --- | ---: | ---: | ---: | --- |
| 企业双列布局，日期开启 | 70 | 70 | 0 | 68 项资料值全部正确；拆分日期对应多个控件 |
| 银行 / 国企纵向布局，日期开启 | 78 | 78 | 0 | 68 项资料值全部正确；额外覆盖联动年月日 |
| 企业布局，日期关闭 | 50 | 50 | 20 个日期字段排除 | 其余资料正确，日期保持为空 |
| 控件拒绝、持续加载、卡住日历 | 16 | 13 | 3 个字段 | 拒绝项未提交；日历超时跳过；其他字段继续填写 |

测试覆盖两段教育、三段项目、实习、校园、奖项、语种 / 熟练度 / 考试 / 成绩。学校候选延迟 2.8 秒及 5.2 秒，必须真实点击候选；年份改变后替换月份控件；学院事件触发学校输入框重新创建。检查协议未勾选、上传和提交计数均为零，并在完成后继续观察 500 毫秒，确认没有后续写入。

第一轮测试发现并修复：原生年份选择器与月份网格组合无法提交；驼峰 `endDateDay` 未识别成日；职责描述、组织名称和考试日期等别名漏匹配。界面检查覆盖 960 像素确认窗口和 560 像素窄窗口，展示资料选择、预览、处理进度及部分跳过结果。

复现：`node tests/browser/run.mjs`。指定单个场景：`node tests/browser/run.mjs enterprise-no-dates`。报告和截图保存在 `.preview/`，不会提交到 Git。

这是可重复的模拟表单验收，不代表已在企业登录后的官网、真实 DeepSeek 响应或浏览器后台休眠场景中全部验证通过。
